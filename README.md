# StaionSign-Maker
自分が作ってる架空鉄道用に作った駅名標メーカーです。

## 使い方
次の項目を設定してください。
- 路線カラー
- ナンバリングカラー
- ナンバリングの形状、路線記号、駅番号
- 駅名(日本語、ひらがな、英語)
- 次駅(左、右)の駅名(日本語、英語)

### 例
- 路線カラー：#f86b00
- ナンバリングカラー：#f00046
- ナンバリングの形状、路線記号、駅番号：角丸四角、B、01
- 駅名(日本語、ひらがな、英語)：さつたば、さつたば
- 次駅(左、右)の駅名(日本語、英語)：
